# Evidence scope

`sensor-frame-smoke.json` is a sanitized transcription of one observed Unity–ROS 2–Python round trip. It records three successful, sequence-correlated responses from one Editor Play Mode run.

The result is a smoke test, not a latency benchmark or a long-duration stability claim. The private scene, trained model, datasets, raw Unity logs, and raw ROS logs are intentionally excluded. This repository presents implementation evidence; it does not claim to be a self-contained reproduction package.
